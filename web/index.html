LP/QP Solver

PDHG

Primal-Dual Hybrid Gradient (Chambolle-Pock). GPU-accelerated via CuPy. Adaptive restart, spectral step-size. State-of-the-art for large sparse LP.

GPU/CuPy Adaptive Restart Spectral Steps
Best for Very Large LP

ADMM

Adaptive ρ Active Set Distributed
Best for QP / MIQP
